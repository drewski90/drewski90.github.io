## Overview

A Goddess’s Touch is a full-stack commerce and operations platform built to replace
manual scheduling, fragmented payments, and ad-hoc staff coordination.

The system centralizes bookings, online payments, staff scheduling, and affiliate
referrals into a single real-time operational platform.


## Who Uses the System

**Staff / Team Members**
- Manage availability
- Manage appointments
- View daily schedules

**Customers**
- Browse services
- Book appointments
- Pay online in real time

**Affiliates**
- Generate tracked referral links
- Share links
- Drive bookings


## Core Workflows

### Customer Booking
- Customers browse services
- Select time slots
- Pay online via Square

### Staff Scheduling
- Set availability
- Manage appointments
- View daily schedules

### Business Management
- Owner manages pricing
- Tracks revenue
- Manages staff roles

### Affiliate Referrals
- Generate referral links
- Track conversions
- Attribute bookings


## Platform Capabilities

- Real-time booking calendar
- Square payment processing
- Staff administration dashboard
- Appointment CRUD workflows
- Affiliate referral attribution
- Role-based access control
